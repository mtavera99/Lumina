Cómo exportar: abre la pieza, pulsa «Activar modo exportar (1080 px)», clic derecho sobre la pieza → Inspeccionar → clic derecho en el nodo <div class="art"> → Capture node screenshot. Verifica que el archivo diga 1080×1350 o 1080×1920; si dice 324×405, no activaste el modo exportar.

Estas páginas llevan noindex para no aparecer en buscadores. Aun así el repositorio es público, así que no pongas aquí nada que no pueda verse desde fuera.
